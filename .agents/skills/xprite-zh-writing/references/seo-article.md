# SEO 文章

站内 SEO 文 = 一个意图答清楚 + snippet 值得点 + 诚实对比 + 链回工具；不为长度或同词密度写作。

站内教程、对比、功能页、帮助/FAQ、资源页（含 `/tools/*`）。先写 zh-CN，再单独重写成 English（不要机翻腔）。

## 站点信息架构

- `/about` = SEO 落地；根路径 `/` = 工具/编辑器。
- 只有搜索落地（`/about`、`/compare/*`、`/tools/*`）用 `/{lang}/`；工作区 `/`、`/editor` **无语言前缀**。落地页链进编辑器时去掉 lang。
- 无自动语言跳转；语言切换 = 换对应 URL。
- 默认 **不要往 /about 英雄区塞 SEO 长文**；可见改动先问清楚再动。SEO 优先 title/meta、结构化、内链、off-page。

## Title / meta

- Title：主查询词靠前；约 50–60 字符可见（中文约 25–32 字）。
- Meta description：约 150–160 字符；**前约 120 字符内写清意图 + 价值**；竞品名尽量别抢前段。
- Title 与 H1 意图一致即可，不必逐字相同。
- slug：英文 slug 稳定；中文落地走 `/{lang}/...`，不要把中文硬塞进全局唯一 slug 规则里写混。

## 特别要注意的地方

- 一页一个搜索意图；主意图词在 Title、H1、slug、首段、相关 H2 **对齐**，禁止全文同一串词硬塞。
- 首屏答案先行：能不能做、怎么做、几步。首段给可引用的事实句（平台、价格模型、格式如 `.aseprite`、是否要装 App）——主张可核验，少空话。
- 每页一个 H1；H2 带具体信息与意图词。超过 5 个 H2 可加目录（UX 建议，不是硬规则）。
- 字数是软目标，下限可破：宁短而答完意图，勿为凑字灌水。教程约 1,200–2,500 字；对比约 1,200–2,000 字；功能约 600–1,200 字；帮助约 150–400 字。`/tools/*` 资源页：**工具首屏 Convert/动作优先 + 一段独有说明**，字数次要。
- 对比表：每格用标记开头——✅ 支持/好、⚠️ 部分/有前提、❌ 不支持；价格行用 🆓 或 💰。无障碍/纯文本场景可用「支持 / 部分 / 不支持」。标记后跟约 ≤12 字短句，同行结构一致，如「✅ iCloud 同步」「⚠️ 手动存文件」。装不下的细节放到表下列表或正文。核对不上写 —；整行多半是 — 就删行。格子写事实，不写形容词；每篇对比页 **必写**「{对手} 做得更好的地方」。
- 内链每页至少 3 条。对比/教程/功能页：至少各有一条指向相关 `/tools/{x}`，并有一条进编辑器（`/` 或 `/editor`，**链接不要带 `/{lang}/` 前缀**）。对比页可链 `/about` how-it-works（若该语有）。
- FAQ：3–6 个真实问法；第一句就是答案；问答可被摘进摘要/GEO。有条件再挂 FAQPage JSON-LD（实现归工程，文案先写可挂载的问答）。
- frontmatter 维护 published/updated。段落保持短（约 30–80 字）。

## 对比页骨架（建议顺序）

H1（意图）→ 首屏结论（谁适合什么）→ 对比表 →「对手更好的地方」→ Xprite 怎么做（步骤）→ CTA（相关 tool + 编辑器）→ FAQ。

## 图

- 站内页优先真实产品截图；表意截图写简短 alt（与意图相关）；已有文字标签的装饰图标不要堆 SEO alt。
- 对比表旁的示意：整图无总标题/副标题，多小图各带图例、不写「图 N」。
- 需要流程图时标签用「动词 + 宾语」。
