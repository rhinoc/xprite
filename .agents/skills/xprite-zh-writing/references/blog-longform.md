# 博客长文

个人研究长文、Notion 深度文（如 Fix-AI）。

## 特别要注意的地方

- 结构：背景 → 问题（用具体事实与数字说明）→ 已有方案的具体缺陷 → 我的方案 → 对照与多场景。
- 对照只对调研过的成熟方案。
- 浅有深：外层好懂，紧接着给精确技术名。
- 过程词、PR、内部开关、工作区路径只进临时文件或评论；正文保持成品。
- 改 Notion 时原地改，保留行内评论；过时块直接删掉。
- 长度跟着任务走；用长文叙事，站点 SEO 骨架见 `seo-article.md`。

## 图与图表

### 图要做什么

- 每一步算法或关键结果，尽量配一张能看懂的图（流程图、对照拼图、实测截图），少用纯文字复述画面。
- 对照图用少量拼版，主体裁紧，少留大块空白；流程 + 步骤结果需要同屏看时，合成一张横图，不要上下拆成两张竖条。
- 生图脚本与中间 HTML 放文章外的源码页（Notion Sources），正文只嵌成品图。

### 倾向用什么工具

- 关系图 / 流程图 / 谱系图：Python 调 Graphviz 出图，再用 Pillow 拼图例、拼版、加白缝。
- 对照拼版、裁切、横图合成：Pillow。
- Notion 能直接渲染 Mermaid 时可用 Mermaid；需要 Graphviz 质感或长图时仍走脚本出 PNG，再嵌进正文。
- 质量参照：像素字体谱系图一类 Graphviz + Pillow 成品，不要只做照片条带拼贴。
