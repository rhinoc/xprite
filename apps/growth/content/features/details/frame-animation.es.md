# Animación cuadro a cuadro

Agrega y ordena cuadros en la línea de tiempo con papel cebolla. Las etiquetas dividen la animación y los cels vinculados comparten una imagen entre cuadros.

## Por dónde empezar

- Agrega cuadros en la línea de tiempo y dibuja o modifica cada uno.
- Activa **Ver → Mostrar papel cebolla** para ver los cuadros cercanos. **Cuadro → Etiquetas** pone nombre a las secciones de la animación.
- Usa **Cuadro → Duplicar cel(s) vinculado(s)** para compartir una imagen entre cuadros o **Cuadro → Invertir orden de los cuadros** para invertir su orden.

## Uso y guardado

Usa **Archivo → Exportar → Exportar como...** para animaciones GIF, APNG o WebP. También puedes [exportar una hoja de sprites](/features/export-images-and-animation/) para reunir los cuadros en una sola imagen.
