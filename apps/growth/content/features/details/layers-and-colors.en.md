# Layers and colors

Organize artwork in layers and use RGB, grayscale or indexed color. Import palettes, generate colors from an image, and adjust hue, brightness or color curves.

## Where to start

- Select a layer in the layer list to work on that part of your image.
- Choose RGB, grayscale or indexed color under **Sprite → Color Mode**. Import a palette or generate one from an image.
- Use **Edit → Adjustments** for brightness, hue or color curves, and **Select → Color Range** to select a color.

## Using and saving

Layers organize the artwork, while color mode determines how colors are represented. Save as `.aseprite` to keep this editing information.
