# Animação quadro a quadro

Adicione e organize quadros na linha do tempo com pele de cebola. Tags dividem a animação em partes, e cels vinculados compartilham uma imagem entre quadros.

## Por onde começar

- Adicione quadros na linha do tempo e desenhe ou altere cada um.
- Ative **Exibir → Mostrar pele de cebola** para ver os quadros vizinhos. **Quadro → Tags** dá nome às partes da animação.
- Use **Quadro → Duplicar célula(s) vinculada(s)** para compartilhar uma imagem entre quadros ou **Quadro → Inverter ordem dos quadros** para inverter a ordem.

## Uso e salvamento

Use **Arquivo → Exportar → Exportar como...** para animações em GIF, APNG ou WebP. Você também pode [exportar uma sprite sheet](/features/export-images-and-animation/) para juntar os quadros em uma imagem.
