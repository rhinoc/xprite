# Arrange your workspace

Move, resize and dock panels, then save the layout. Save projects in your browser or as files, and add Xprite to your Home Screen for offline editing.

## Where to start

- Drag a panel handle or tab to dock it, place it beside another panel, or combine panels into tabs.
- Use the handle or tab menu to float a panel or collapse it into a button.
- Open **Workspace layout** beside the document tabs and use **Save current...** to save the arrangement.

## Using and saving

Automatic mode chooses a layout for the window size. Editing a saved layout overwrites it; save another copy first when you want to keep both arrangements.
