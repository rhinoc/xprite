# Crear tilemaps

Monta escenas con capas de mapa de tiles y exporta tilesets como PNG. Reutiliza tiles para crear mapas de juegos y fondos repetidos.

## Por dónde empezar

- Elige **Capa → Nuevo... → Nueva capa de mapa de tiles**.
- Coloca tiles en la capa para montar una escena con piezas reutilizables.
- Con la capa de mapa de tiles seleccionada, usa **Archivo → Exportar → Exportar tileset** para exportar un PNG.

## Uso y guardado

El PNG del tileset conserva los tiles de origen. Guarda un proyecto `.aseprite` para seguir editando el mapa.
