# Grabar el proceso de dibujo

Graba tu trabajo desde el primer boceto hasta el sprite terminado. Reproduce la grabación o expórtala como GIF con los controles de proceso de dibujo.

## Por dónde empezar

- Elige **Sprite → Proceso de dibujo → Iniciar grabación**.
- Elige **Detener grabación** para abrir la repetición o **Continuar grabación** para seguir grabando.
- Reproduce las grabaciones en **Repetición del dibujo…** o exporta un archivo `.xprite-replay` o un GIF del lienzo.

## Uso y guardado

Las repeticiones se guardan con los proyectos del navegador. Los archivos PNG y Aseprite no incluyen grabaciones, así que exporta un archivo `.xprite-replay` antes de cambiar de dispositivo o navegador.
