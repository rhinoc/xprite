# Export images and animation

Export PNG images and sprite sheets, or animated GIF, APNG and WebP. Import existing images or animations to keep editing them.

## Where to start

- Choose **File → Export → Export As...** for an image or animation.
- Choose **Export Sprite Sheet** for a PNG sheet, with optional JSON data.
- Use **Export Tileset** to export the tiles from a tilemap layer as PNG.

## Using and saving

PNG works for individual frames, while GIF, APNG and WebP support animation. Image and animation exports do not retain project layers and tags; keep an `.aseprite` project for future edits.
