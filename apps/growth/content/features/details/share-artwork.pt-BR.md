# Compartilhar arte

Crie um link ou QR code que abre seu sprite para ver e editar. Os links são gerados no seu dispositivo, sem enviar o arquivo do projeto.

## Por onde começar

- Escolha **Arquivo → Compartilhar...**.
- Use **Copiar link** para enviar um link ou **Salvar QR code** para salvar uma imagem QR.
- Quem receber pode ver e editar a arte abrindo o link ou escaneando o código.

## Uso e salvamento

Os links são gerados no seu dispositivo, sem enviar a arte. Qualquer pessoa com o link completo pode abri-lo. Os links não expiram e não podem ser revogados; compartilhe o quadro atual ou as camadas visíveis quando o projeto for grande demais.
