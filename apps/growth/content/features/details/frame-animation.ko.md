# 프레임 단위 애니메이션

타임라인에서 프레임을 추가하고 배치하며, 어니언 스킨을 참고해 그립니다. 태그로 애니메이션을 구간으로 나누고, 연결된 셀로 여러 프레임이 한 이미지를 공유합니다.

## 시작하기

- 타임라인에서 프레임을 추가하고 프레임마다 그리거나 수정하세요.
- **보기 → 어니언 스킨 표시**를 켜면 앞뒤 프레임을 참고할 수 있습니다. **프레임 → 태그**로 애니메이션 구간에 이름을 붙입니다.
- **프레임 → 연결된 셀로 복제**로 여러 프레임이 한 이미지를 공유하게 하고, **프레임 → 프레임 순서 뒤집기**로 순서를 뒤집을 수 있습니다.

## 사용과 저장

GIF, APNG, WebP 애니메이션은 **파일 → 내보내기 → 다른 이름으로 내보내기...**를 사용하세요. 프레임을 이미지 한 장에 배치하려면 [스프라이트 시트로 내보낼](/features/export-images-and-animation/) 수도 있습니다.
