# Camadas e cores

Organize a arte em camadas e use cor RGB, tons de cinza ou indexada. Importe paletas, gere cores a partir de uma imagem e ajuste matiz, brilho ou curvas de cor.

## Por onde começar

- Selecione uma camada na lista de camadas para trabalhar naquela parte da imagem.
- Escolha RGB, tons de cinza ou cor indexada em **Sprite → Modo de cor**. Importe uma paleta ou gere uma a partir de uma imagem.
- Use **Editar → Ajustes** para brilho, matiz ou curvas de cor, e **Selecionar → Intervalo de cores** para selecionar uma cor.

## Uso e salvamento

As camadas organizam a arte, e o modo de cor define como as cores são representadas. Salve como `.aseprite` para manter essas informações.
