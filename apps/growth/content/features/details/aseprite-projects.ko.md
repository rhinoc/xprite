# Aseprite 프로젝트 편집

프로젝트를 열어도 레이어, 프레임, 태그가 유지됩니다. `.aseprite`로 저장해 Aseprite에서 이어서 작업하세요. Aseprite 스크립트나 확장 기능은 실행할 수 없습니다.

## 시작하기

- **파일 → 열기...**로 `.ase` 또는 `.aseprite` 프로젝트를 선택하세요.
- 가져온 레이어, 프레임, 태그를 확인하고 편집을 이어 가세요.
- **파일 → 다른 이름으로 저장**으로 기기에 `.aseprite` 파일을 저장하면 Aseprite에서 다시 열 수 있습니다.

## 사용과 저장

Xprite는 Aseprite 스크립트나 확장 기능을 실행할 수 없으며, 일부 프로젝트는 완전히 호환되지 않을 수 있습니다. 미리 보기와 PNG·GIF 내보내기는 [Aseprite 뷰어](/tools/viewer/)를 여세요.
