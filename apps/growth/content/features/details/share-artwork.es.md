# Compartir tu arte

Crea un enlace o un código QR que abre tu sprite para verlo y editarlo. Los enlaces se generan en tu dispositivo sin subir el archivo del proyecto.

## Por dónde empezar

- Elige **Archivo → Compartir...**.
- Usa **Copiar enlace** para enviar un enlace o **Guardar código QR** para guardar una imagen QR.
- Quien lo reciba puede ver y editar el arte abriendo el enlace o escaneando el código.

## Uso y guardado

Los enlaces se generan en tu dispositivo sin subir tu arte. Cualquiera con el enlace completo puede abrirlo. Los enlaces no caducan ni se pueden revocar; comparte el cuadro actual o las capas visibles si el proyecto es demasiado grande.
