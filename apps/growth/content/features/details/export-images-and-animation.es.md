# Exportar imágenes y animaciones

Exporta imágenes PNG y hojas de sprites, o animaciones GIF, APNG y WebP. Importa imágenes o animaciones existentes para seguir editándolas.

## Por dónde empezar

- Elige **Archivo → Exportar → Exportar como...** para una imagen o animación.
- Elige **Exportar hoja de sprites** para una hoja PNG, con datos JSON opcionales.
- Usa **Exportar tileset** para exportar como PNG los tiles de una capa de mapa de tiles.

## Uso y guardado

PNG sirve para cuadros sueltos, mientras que GIF, APNG y WebP admiten animación. Las exportaciones de imagen y animación no conservan las capas ni las etiquetas; guarda un proyecto `.aseprite` para editarlo más adelante.
