# Capas y colores

Organiza tu arte en capas con color RGB, escala de grises o indexado. Importa paletas, sácalas de una imagen y ajusta tono, brillo o curvas de color.

## Por dónde empezar

- Selecciona una capa en la lista de capas para trabajar en esa parte de la imagen.
- Elige RGB, escala de grises o color indexado en **Sprite → Modo de color**. Importa una paleta o genérala a partir de una imagen.
- Usa **Editar → Ajustes** para el brillo, el tono o las curvas de color, y **Seleccionar → Rango de color** para seleccionar un color.

## Uso y guardado

Las capas organizan el arte y el modo de color define cómo se representan los colores. Guarda como `.aseprite` para conservar esta información.
