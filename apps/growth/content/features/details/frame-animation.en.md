# Frame animation

Add and arrange frames on the timeline, with onion skinning for reference. Tags divide animations into sections, while linked cels share an image across frames.

## Where to start

- Add frames on the timeline and draw or modify each frame.
- Enable **View → Show Onion Skin** to reference nearby frames. **Frame → Tags** names sections of an animation.
- Use **Frame → Duplicate Linked Cel(s)** to share an image across frames, or **Frame → Reverse Frames** to reverse their order.

## Using and saving

Use **File → Export → Export As...** for GIF, APNG or WebP animation. You can also [export a sprite sheet](/features/export-images-and-animation/) to arrange frames into one image.
