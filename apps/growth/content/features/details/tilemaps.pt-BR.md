# Criar tilemaps

Monte cenários com camadas de tilemap e exporte tilesets em PNG. Reaproveite tiles para criar mapas de jogos e cenários repetidos.

## Por onde começar

- Escolha **Camada → Novo... → Nova camada de tilemap**.
- Coloque tiles na camada de tilemap para montar um cenário com peças reutilizáveis.
- Com a camada de tilemap selecionada, use **Arquivo → Exportar → Exportar tileset** para exportar um PNG.

## Uso e salvamento

O PNG do tileset preserva os tiles de origem. Salve um projeto `.aseprite` para continuar editando o mapa.
