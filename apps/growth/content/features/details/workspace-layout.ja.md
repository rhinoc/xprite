# ワークスペースを整える

パネルを移動・リサイズ・ドッキングしてレイアウトを保存。プロジェクトはブラウザかファイルに保存でき、Xprite をホーム画面に追加すればオフラインでも編集できます。

## 始め方

- パネルのハンドルやタブをドラッグして、ドッキングしたり、他のパネルの横に置いたり、タブとしてまとめたりします。
- ハンドルやタブのメニューで、パネルをフローティングにしたりボタンに折りたたんだりできます。
- ドキュメントタブの横にある **ワークスペースのレイアウト** を開き、**現在のレイアウトを保存…** で配置を保存します。

## 使い方と保存

自動モードはウィンドウサイズに合わせてレイアウトを選びます。保存済みのレイアウトを編集すると上書きされるので、両方の配置を残したいときは先に別のコピーとして保存してください。
