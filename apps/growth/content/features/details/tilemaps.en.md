# Build tilemaps

Assemble scenes with tilemap layers and export tilesets as PNG. Reuse tiles to create game maps and repeating scene artwork.

## Where to start

- Choose **Layer → New... → New Tilemap Layer** to create a tilemap.
- Place tiles on the tilemap layer to assemble a scene from reusable artwork.
- With a tilemap layer selected, use **File → Export → Export Tileset** to export a PNG.

## Using and saving

A tileset PNG preserves the source tiles. Save an `.aseprite` project to keep editing the map.
