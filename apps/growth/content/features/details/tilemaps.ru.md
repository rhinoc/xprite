# Создание тайлмапов

Собирайте сцены на слоях тайловой карты и экспортируйте тайлсеты в PNG. Повторно используйте тайлы для игровых карт и повторяющихся фонов.

## С чего начать

- Выберите **Слой → Создать... → Новый слой тайловой карты**.
- Размещайте тайлы на слое, собирая сцену из повторяющихся элементов.
- Выбрав слой тайловой карты, используйте **Файл → Экспорт → Экспорт тайлсета**, чтобы сохранить PNG.

## Использование и сохранение

PNG тайлсета сохраняет исходные тайлы. Чтобы продолжить редактировать карту, сохраните проект `.aseprite`.
