# Edit Aseprite projects

Keep layers, frames and tags when opening projects. Save as `.aseprite` to continue in Aseprite. Xprite cannot run Aseprite scripts or extensions.

## Where to start

- Use **File → Open...** to select an `.ase` or `.aseprite` project.
- Inspect the imported layers, frames and tags, then continue editing.
- Use **File → Save As** to save a `.aseprite` file on your device and open it again in Aseprite.

## Using and saving

Xprite cannot run Aseprite scripts or extensions, and some projects may not be fully compatible. For previewing and PNG or GIF export, open the [Aseprite Viewer](/tools/viewer/).
