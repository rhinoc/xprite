# Record your drawing process

Record work from the first sketch to the finished sprite. Replay the recording or export it as a GIF using the editor's drawing process controls.

## Where to start

- Choose **Sprite → Drawing Process → Start recording**.
- Choose **Stop recording** to open the replay, or **Continue recording** to keep recording.
- Play recordings in **Drawing Replay…**, or export a `.xprite-replay` file or a canvas GIF.

## Using and saving

Replays are saved with browser projects. PNG and Aseprite files do not include recordings, so export a `.xprite-replay` file before changing devices or browsers.
