# フレームごとにアニメーション

タイムラインでフレームを追加・並べ替え、オニオンスキンを参考に描けます。タグでアニメーションを区切り、リンクセルで複数フレームに同じ画像を共有できます。

## 始め方

- タイムラインでフレームを追加し、各フレームを描いたり修正したりします。
- **表示 → オニオンスキンを表示** をオンにすると前後のフレームを参考にできます。**フレーム → タグ** でアニメーションの区間に名前を付けます。
- **フレーム → リンクセルとして複製** で複数フレームに同じ画像を共有し、**フレーム → フレームを逆順にする** で順番を反転できます。

## 使い方と保存

GIF、APNG、WebP のアニメーションは **ファイル → エクスポート → 名前を付けてエクスポート...** で書き出せます。フレームを 1 枚の画像に並べるには[スプライトシートをエクスポート](/features/export-images-and-animation/)することもできます。
