# 작업 공간 정리

패널을 옮기고, 크기를 바꾸고, 도킹한 뒤 레이아웃을 저장합니다. 프로젝트는 브라우저나 파일로 저장하고, 홈 화면에 추가하면 오프라인에서도 편집할 수 있습니다.

## 시작하기

- 패널 핸들이나 탭을 끌어서 도킹하거나, 다른 패널 옆에 놓거나, 탭으로 합치세요.
- 핸들이나 탭 메뉴로 패널을 떠 있는 창으로 만들거나 버튼으로 접을 수 있습니다.
- 문서 탭 옆의 **작업 공간 레이아웃**을 열고 **현재 레이아웃 저장…**으로 배치를 저장하세요.

## 사용과 저장

자동 모드는 창 크기에 맞춰 레이아웃을 고릅니다. 저장된 레이아웃을 편집하면 덮어쓰므로, 두 배치를 모두 남기려면 먼저 다른 사본으로 저장하세요.
