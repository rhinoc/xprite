# Exportar imagens e animações

Exporte imagens PNG e sprite sheets ou animações em GIF, APNG e WebP. Importe imagens ou animações existentes para continuar editando.

## Por onde começar

- Escolha **Arquivo → Exportar → Exportar como...** para uma imagem ou animação.
- Escolha **Exportar sprite sheet** para uma folha PNG, com dados JSON opcionais.
- Use **Exportar tileset** para exportar os tiles de uma camada de tilemap como PNG.

## Uso e salvamento

PNG serve para quadros individuais, enquanto GIF, APNG e WebP suportam animação. Exportações de imagem e animação não guardam camadas nem tags; mantenha um projeto `.aseprite` para edições futuras.
