# Draw pixel art

Draw with pencils, fills, gradients and shape tools. Refine details with selections and custom brushes, add text, and use symmetry or tiled previews.

## Where to start

- Create or open a sprite in the editor, then choose a pencil, fill or shape tool from the toolbar.
- Open **View → Symmetry Options** for mirrored drawing, or **View → Tiled Mode** to preview a repeating pattern.
- Use selections to restrict edits. **Edit → New Brush** turns the selected artwork into a brush.

## Using and saving

These drawing tools work on still images and animation frames. See [Layers and colors](/features/layers-and-colors/) to organize artwork and choose colors.
