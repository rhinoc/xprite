# 이미지와 애니메이션 내보내기

PNG 이미지와 스프라이트 시트, 애니메이션 GIF, APNG, WebP로 내보냅니다. 기존 이미지나 애니메이션을 가져와 계속 편집할 수도 있습니다.

## 시작하기

- 이미지나 애니메이션은 **파일 → 내보내기 → 다른 이름으로 내보내기...**를 선택하세요.
- PNG 시트는 **스프라이트 시트 내보내기**를 선택하세요. JSON 데이터도 함께 내보낼 수 있습니다.
- 타일맵 레이어의 타일을 PNG로 내보내려면 **타일셋 내보내기**를 사용하세요.

## 사용과 저장

PNG는 개별 프레임에, GIF, APNG, WebP는 애니메이션에 알맞습니다. 이미지와 애니메이션 내보내기에는 프로젝트의 레이어와 태그가 남지 않으니, 나중에 편집할 수 있도록 `.aseprite` 프로젝트를 보관하세요.
