# Dibujar en tabletas y móviles

Dibuja con el dedo o un lápiz óptico. Mueve el lienzo con dos dedos, pellizca para hacer zoom y toca con dos dedos para deshacer. La barra de accesos rápidos ofrece los modificadores más comunes para editar con el tacto.

## Por dónde empezar

- Dibuja con el dedo o un lápiz óptico. Mueve el lienzo con dos dedos, pellizca para hacer zoom y toca con dos dedos para deshacer.
- Abre **Ver → Mostrar → Barra de accesos rápidos** para modificadores como **Mantener proporción**, **Desde el centro** y **Duplicar al arrastrar**.
- Desliza a lo largo de una barra para llegar a las herramientas que no caben en la pantalla.

## Uso y guardado

Añade Xprite a tu pantalla de inicio para abrirlo como una app. Tras la configuración inicial online, puedes editar sin conexión. Tu arte se queda en el navegador actual o en archivos del dispositivo.
