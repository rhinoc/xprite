# 태블릿과 휴대폰에서 그리기

손가락이나 펜으로 그립니다. 두 손가락으로 이동하고, 핀치로 확대/축소하며, 두 손가락 탭으로 실행 취소합니다. 단축 도구 모음으로 보조 키 동작을 씁니다.

## 시작하기

- 손가락이나 펜으로 그리세요. 두 손가락으로 이동하고, 핀치로 확대/축소하며, 두 손가락 탭으로 실행 취소합니다.
- **보기 → 표시 → 단축 도구 모음**을 열면 **비율 고정**, **중심에서 그리기**, **드래그하여 복제** 같은 보조 키 동작을 쓸 수 있습니다.
- 화면에 다 들어가지 않는 도구는 도구 모음을 따라 밀어서 볼 수 있습니다.

## 사용과 저장

Xprite를 홈 화면에 추가하면 앱처럼 열 수 있습니다. 처음에 온라인으로 준비한 뒤에는 오프라인에서도 편집할 수 있습니다. 작품은 현재 브라우저나 기기 파일에 남습니다.
