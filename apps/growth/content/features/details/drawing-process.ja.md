# 描画過程を録画

最初のラフから完成したスプライトまでを録画。エディターの描画過程の機能で、録画を再生したり GIF でエクスポートしたりできます。

## 始め方

- **スプライト → 描画過程 → 録画を開始** を選びます。
- **録画を終了** でリプレイを開くか、**録画を再開** で録画を続けます。
- **描画過程のリプレイ…** で録画を再生したり、`.xprite-replay` ファイルやキャンバス GIF をエクスポートしたりできます。

## 使い方と保存

リプレイはブラウザ内のプロジェクトと一緒に保存されます。PNG や Aseprite ファイルには録画が含まれないので、端末やブラウザを変える前に `.xprite-replay` ファイルをエクスポートしてください。
