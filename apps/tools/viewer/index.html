Is the Aseprite file viewer free?

Yes. Free, no account, and no install. Open .aseprite and .ase files in your browser.

Do I need to upload my .aseprite file?

No. Processing stays on your device. Open or drop an .ase or .aseprite file—the file is never uploaded to a server.

Which Aseprite files can I open?

.ase and .aseprite projects. The viewer previews layers and frames in the browser. Large or unsupported projects may be rejected.

Can I export PNG or GIF?

Yes. Export the current frame as PNG, or the animation as GIF. PNG and GIF do not keep project layers or tags.

Can I edit the file in Xprite?

Yes. Edit this file in Xprite opens the original project in the Xprite pixel editor as a new project, with its layers and tags.

Does hiding a layer change my file?

No. Layer visibility affects the preview and the export. The original file stays unchanged.

Is this the official Aseprite app?

No. This is Xprite · xprite.cc, a free browser pixel editor. It is independent of Aseprite. File-format support is not a guarantee of complete compatibility.
