# Pixel-art craft rules for Xprite agents

The pixel-art craft knowledge base, adapted for `window.xpriteAgent` from the
Aseprite AI Artist project (MIT). Read `00-adapter.md` for how their tool names
map to this editor's API, then start at `00-core/00-core-principles.md`.

Files are grouped by band: `0x` core discipline, `1x` technique, `2x` colour and
materials, `3x` characters, `4x` animation, `5x` creatures, `6x` environments,
`7x` objects and 3D, `8x` effects and UI, `9x` style.
