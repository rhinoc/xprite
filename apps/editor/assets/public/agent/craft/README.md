# Pixel-art craft rules for Xprite agents

Index of the pixel-art craft handbook for `window.xpriteAgent`, adapted from the Aseprite AI Artist project (MIT). Read `00-core-principles` first. Bands: `0x` core, `1x` technique, `2x` colour, `3x` characters, `4x` animation, `5x` creatures, `6x` environments, `7x` objects and 3D, `8x` effects and UI, `9x` style.
