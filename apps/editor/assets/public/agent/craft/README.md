# Pixel-art craft rules for Xprite agents

The pixel-art craft knowledge base, adapted for `window.xpriteAgent` from the
Aseprite AI Artist project (MIT). Read `00-adapter.md` for how their tool names
map to this editor's API, then start at `00-core-principles.md`.

## Contents

- `0x` core discipline: `00`–`07` — the inspect→draw→look→fix loop, palette,
  shading, silhouette, outlines, animation, layers, review.
- `1x` technique: `10`–`14` — lines, clusters, anti-aliasing, dithering,
  readability.
- `2x` colour & materials: `20`–`24` — colour, limited palettes, hard and
  soft materials, lighting.
- `3x` characters: `30`–`38` — proportions, anatomy, head/face/eyes, hands,
  hair, character design, views, portraits.
- `4x` animation: `40`–`47` — timing, idle, walk/run, jump/fall/land,
  attacks, secondary motion, sub-pixel, top-down.
- `5x` creatures: `50`–`54` — quadrupeds, animal gaits, birds, small
  creatures, monsters.
- `6x` environments: `60`–`67` — skies, landscapes, parallax, trees, water,
  ground/rocks/grass, tiles/autotiling, architecture.
- `7x` objects & 3D: `70`–`75` — perspective, isometric, 3D forms, props,
  vehicles, rotation/turnarounds.
- `8x` effects & UI: `80`–`84` — fire/smoke/magic, impacts/game-feel,
  particles/weather, UI/icons, bitmap fonts.
- `9x` style: `90`–`92` — platform styles, composition/scenes,
  generated-art tells.
