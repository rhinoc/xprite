Aseprite English UI strings

Selected English translations from `data/strings/en.ini` appear in:

- `apps/editor/assets/commands/libresprite-main-menu.json` (visible menu labels)
- `apps/editor/assets/commands/aseprite-tool-tips.json` (tool names, help text, preview/timeline labels)
- `apps/editor/src/i18n/locales/en.json` (English UI label catalog)
- selected labels in the current editor dialogs and controls

Source: Aseprite `data/strings/en.ini`, snapshot commit

Aseprite Japanese and Korean UI strings

The Japanese and Korean editor catalogs (`apps/editor/src/i18n/locales/ja.json`
and `ko.json`) were translated for this editor and use the community Aseprite
language packs as their terminology reference, so that tool, command and panel
names match what Japanese and Korean Aseprite users already know. Individual
labels that coincide with those packs are adapted from them; the catalogs are
not copies of the packs.
