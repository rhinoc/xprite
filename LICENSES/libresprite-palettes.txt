into `apps/editor/assets/palette-presets/libresprite/`. LibreSprite's README
states that the program is distributed under GPL-2.0. This project redistributes
the LibreSprite palette set under GPL-2.0-only and preserves each file's
original comments and author/source information.

PICO-8's creator separately makes the palette available under CC0 1.0; see
https://www.lexaloffle.com/pico-8.php?page=faq. Solarized retains its separate
MIT license; see `solarized.txt`.

`*.gpl` is the GIMP Palette file format and does not mean GNU GPL. In this
inventory, GPL-2.0-only refers to the LibreSprite source distribution license.
