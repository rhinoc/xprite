# Palette preset review

This file records the item-by-item review of the original 65 Aseprite palette files. The current catalog separately includes the 38 palettes copied from LibreSprite's GPL-2.0 source distribution, AAP-RadiantXV under the PixelJoint permission cited below, five Lospec palettes under creator permissions, and nine Paleto palettes under CC0 1.0. See `LICENSES/libresprite-palettes.txt` and `LICENSES/lospec-palettes.txt` for those separate additions. Several names overlap; decisions in the table refer only to the original Aseprite file path in the second column. They do not describe the separate source copies used in the current catalog. For example, the old Aseprite AAP-Splendor128 file marked “All Rights Reserved” remains excluded, while the current catalog uses the different file as distributed in LibreSprite's GPL-2.0 source tree.

Aseprite's CLA grant applies to contributions submitted by a contributor who signed the agreement. The public repository does not expose signed agreements for these palette creators; for example, the AAP palette additions were committed by Aseprite maintainer David Capello. We therefore do not infer that the palette authors' work is covered by the CLA. Likewise, the CC BY field on Aseprite's theme package applies to that theme package, not to palettes.

The `.gpl` extension means GIMP Palette format; it is not a GNU GPL license.

## Sources and permission findings

- [AAP-64 by Adigun A. Polack](https://pixeljoint.com/pixelart/119466.htm): the author says others are welcome to use the palette in sprites, games, and pixel-art creations. Its catalog entry records this permission and author credit; no CC BY license was found.
- [AAP-RadiantXV competition terms](https://pixeljoint.com/forum/forum_posts.asp?TID=26360): entrants give others permission to use submitted palettes. Its catalog entry records this permission and creator credit.
- [Arne Niklas Jansson’s generic 16-color palette](https://androidarts.com/palette/16pal.htm): the listed RGB values match `ARNE16`, and the author says it is free to use and modify. The separate bonus palettes on the same page do not receive that statement.
- [DB16 by Richard “DawnBringer” Fhager](https://pixeljoint.com/forum/forum_posts.asp?TID=12795): the author explicitly says the palette may be used. The separate [DB32 page](https://pixeljoint.com/forum/forum_posts.asp?TID=16247) provides palette files but no comparable permission statement, so DB32 was removed.
- The [PICO-8 FAQ](https://www.lexaloffle.com/pico-8.php?page=faq) places the PICO-8 palette under CC0 1.0.
- Solarized retains its [upstream MIT license](https://github.com/altercation/solarized/blob/master/LICENSE) in `LICENSES/solarized.txt`.
- Aseprite's [palette-extension docs](https://www.aseprite.org/docs/extensions/palettes/) describe author metadata but no default license. The palette manifests for [AAP](https://github.com/aseprite/aseprite/blob/main/data/extensions/adigunpolack-palettes/package.json), [Arne](https://github.com/aseprite/aseprite/blob/main/data/extensions/arne-palettes/package.json), [Davit Masia](https://github.com/aseprite/aseprite/blob/main/data/extensions/davitmasia-palettes/package.json), [DawnBringer](https://github.com/aseprite/aseprite/blob/main/data/extensions/dawnbringer-palettes/package.json), [ENDESGA](https://github.com/aseprite/aseprite/blob/main/data/extensions/endesga-palettes/package.json), [Hyohnoo](https://github.com/aseprite/aseprite/blob/main/data/extensions/hyohnoo-palettes/package.json), [Javier Guerrero](https://github.com/aseprite/aseprite/blob/main/data/extensions/javierguerrero-palettes/package.json), [PineTreePizza](https://github.com/aseprite/aseprite/blob/main/data/extensions/pinetreepizza-palettes/package.json), [PICO-8](https://github.com/aseprite/aseprite/blob/main/data/extensions/pico8-palette/package.json), and [Zughy](https://github.com/aseprite/aseprite/blob/main/data/extensions/zughy-palettes/package.json) contain no `license` field. Aseprite's [author credits](https://github.com/aseprite/aseprite/blob/main/AUTHORS.md) identify some palette creators, but credit alone is not a license. The [submission policy](https://github.com/aseprite/aseprite/blob/main/CONTRIBUTING.md) requires a CLA for code submissions, and the [CLA](https://github.com/igarastudio/cla/blob/main/cla.md) applies to contributions from signers. The AAP pack addition is recorded in an [Aseprite commit by David Capello](https://github.com/aseprite/aseprite/commit/e70af6d434); the public source does not show whether each artist separately signed a CLA for their palette. We do not rely on the CLA as a substitute for a verifiable asset-specific grant.
- Aseprite's [default theme package](https://github.com/aseprite/aseprite/blob/main/data/extensions/aseprite-theme/package.json) explicitly declares CC-BY-4.0. That license is scoped to the theme extension, not the palette packs. None of the 65 reviewed `.gpl` files says CC BY.
- The Xprite project is the source of the brand icon and favicons. It and its
  preview use the separate brand asset license; see `LICENSES/xprite-branding.txt`.

The `.gpl` file extension denotes GIMP Palette format, not the GNU GPL. Missing license information is recorded as “no verifiable redistribution grant found”; removed items are not being declared unlawful or uncopyrightable.

## Current bundled palette sets

The app now bundles the 38 files listed in `LICENSES/libresprite-palettes.txt`
from LibreSprite's `data/palettes` directory. They are redistributed under
GPL-2.0-only, compatible with this project's GPL-2.0-only license. PICO-8's
CC0 and Solarized's MIT grants remain separately recorded in the catalog.
The app also bundles five Lospec palettes under the creator permissions
recorded in `LICENSES/lospec-palettes.txt` and nine Paleto palettes under
CC0-1.0.
