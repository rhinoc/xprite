## Preparation

```sh
blender --background --python scripts/showcase/devices/prepare-models.py
```

The script normalizes orientation and scale into the iPad scene's X-right/Y-up/Z-front coordinates, assigns planar screen UVs, removes the source display artwork, and exports `macbook-pro.glb` and `iphone.glb`. Original device mesh detail and body materials are preserved. The laptop receives a fixed viewing pitch to show its keyboard; the app positions the models in its carousel. Screens use Xprite's own artwork and device-specific native editor captures; see [capture preparation](captures.md). Browser chrome, address typing, and cursor motion are authored for the MacBook demonstration. The iPhone uses portrait editor captures with authored system chrome and the existing licensed hand. The phone source joins its display face to the back-panel object; preparation separates the existing front-facing polygons into a named `Screen` mesh while retaining their original shape. This script does not modify the iPad, hand, or Pencil assets.

`macbook-pro.blend` and `iphone.blend` contain the adapted, editable meshes with packed textures. Running the script replaces those generated files and the two public GLBs; save manual art edits separately before regenerating.

The adapted model files remain CC BY 4.0. The preparation script uses the repository's GPL-2.0-only license. Apple product names identify the represented devices and do not imply endorsement.

The iPhone camera cutout is exported as `DynamicIsland`. Its front face is separated from the screen by 0.01 normalized model units (the source gap was approximately 0.00129), preventing near-coplanar depth flicker during pointer tilt. `prepare-models.py` applies the same separation when regenerating the model. Screen UVs, body materials, hover motion and depth occlusion remain intact.
